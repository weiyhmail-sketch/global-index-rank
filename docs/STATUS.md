## P2 完成 + P3 首页（2026-09-20）

### 最终架构（绕开付费限制）

```
GitHub Actions（每日 UTC 22:00，无超时限制）
  └─ 跑 cloudfunctions/lib 下的同一套 Node 代码
     → dist/snapshot.json (40 KB) + series.json (1.13 MB)
     → 强推到 data 孤儿分支（单提交，历史不膨胀）

云函数 ingest（北京时间 06:10 / 06:20 两次定时触发）
  └─ 从 jsDelivr 取 snapshot.json → 写 index_snapshot/latest    实测 1.3-1.8 秒

云函数 get-snapshot
  └─ 客户端首屏数据入口（集合默认权限禁止客户端直读，走函数免去权限配置）

小程序 pages/index
  └─ 零计算渲染
```

**为什么这么绕**：云开发免费版云函数超时固定 3 秒且**不可调**（控制台点「+」弹出
升级套餐，个人版 ¥19.9/月）。33 个指数 + 汇率需约 36 秒，云函数跑不完；
实测 3 个指数可过、8 个即超时。重活因此全部挪到 Actions。

配两个定时触发器不是冗余：冷启动会吃掉 3 秒里的大半（实测首次调用超时、
预热后仅 1.3-1.8 秒），第二次触发时函数已热，天然充当重试。函数幂等。

### 构建侧预计算

事件锚点与近7日名次变化都在 Actions 侧算好写进快照。客户端若自己算，
需要下载全部日线序列（1.13 MB）；放在构建侧只多出几百个小整数，
快照 20 KB → 40 KB。

增量汇率生效后，每日构建从 35.9 秒降到 **7.8 秒**。

| 页面逻辑（Node 打桩跑 render） | 核心12行数、口径切换、锚点切换、分层切换、汇率拆解乘法校验 **全部通过** |

### 与评审的两处分歧（已实测数据佐证）

**1. 评审建议「人民币降二级，因为 ≈ 美元 + 噪音」——数据不支持，已否决。**

17 个可比市场实测：美元与人民币口径平均差 **4.63pt**，最大 **7.19pt**（韩国）；
**3 个市场涨跌符号相反**（德国 +0.71%→−3.54%、墨西哥 +3.11%→−1.36%、新西兰 +0.45%→−3.91%）。
原因是人民币年内对美元升值 4.33%（7.0010 → 6.6976）。

最终决定比「保留」更进一步：**人民币设为默认口径**——对中文用户这是他实际拿到的收益。

**2. 评审建议「砍掉今日窗口」——推理不成立，已否决。**

其论据是各国「今日」错位一天。但所有窗口都有同样错位，只是分母大显得小；
且「各市场最近一个交易日涨了多少」是定义清晰的问题。
改为**保留窗口 + 把每行数据日期显性化**。

## 第三轮：绕开代理补齐核心数据（2026-09-19）

用户按 TODO 执行 `env -u HTTP_PROXY ...` 后**东财仍然全部失败**。诊断发现是两层问题，
清环境变量对任何一层都无效：

| 层 | 状况 |
|---|---|
| macOS 系统代理 | `scutil --proxy` 中 HTTP/HTTPS/SOCKS 均指向 `127.0.0.1:10808`（Python urllib 会读，curl 不读） |
| **TUN 路由劫持** | 路由表 `128.0/1 → utun28`，比 `default` 更具体 → 全部流量强制进隧道，与环境变量无关 |

**结论：必须关闭代理软件或切到规则模式，`env -u` 解决不了。**

但与其让用户反复开关代理，改为**扩展源链**——找到三条境外 IP 可直连的新浪专用接口：

| 源 | 覆盖 | 历史深度 |
|---|---|---|
| `money.finance.sina.com.cn` CN_MarketData | A 股（上证、沪深300） | 1023 条（约 4 年） |
| `index_us_stock_sina`（akshare 解码私有格式） | 美股（标普500、纳指100、道指） | **22 年**（2004 起） |
| `stock_hk_index_daily_sina` | 港股（恒生、恒生国企） | **13 年**（2013 起） |

这 7 个指数正好是**核心 12 国里缺的全部**（美×3、中×2、港×2），补齐后核心层 12/12 完整。
源链顺序改为「新浪专源 → 东财 → 新浪环球」，专源优先是因为它历史更长且不挑 IP。

> 注意：美股/港股专源依赖 akshare 的私有 K 线解码器，**仅用于本地开发**。
> P2 云函数（Node）里没有 akshare，届时走东财即可（云端 IP 不会被拒）。
