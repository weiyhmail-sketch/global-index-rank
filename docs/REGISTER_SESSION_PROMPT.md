# 新 Session 启动 Prompt（带我注册小程序 + 云开发环境）

> 用法：开一个新的 Claude Code session，工作目录设为本项目根目录
> `~/Desktop/AI工程项目/指数小程序`，把下面 ``` 之间的内容整段贴进去。
>
> 注册过程涉及身份证、手机号等个人信息和微信扫码，**这些必须由你本人操作**。
> 新 session 的角色是陪你走流程、解释每一步、遇到卡点帮你判断，不是替你填表。

---

```
我要注册一个微信小程序，请带着我一步步走完。你负责讲清楚每一步要做什么、
为什么、以及卡住时怎么办；实际的填写、扫码、身份验证由我本人来做。

## 背景（你需要知道的项目上下文）

- 项目在当前目录，是一个「全球股市涨幅排行」小程序：展示全球 45 个国家/地区
  主权股指在不同时间区间的涨幅排名。技术底座（数据抓取、汇率换算、快照计算）
  已经完成并验证，前端设计也已在 HTML 原型上验证完毕（可打开
  prototype/index.html 看实物）。现在缺的就是 AppID 和云开发环境，拿到就能上云。
- 详细进度看 docs/STATUS.md，我的待办清单看 docs/TODO_USER.md（第 5、6 项就是这件事）。

## 关键约束（请务必遵守）

1. **我只有个人主体**，没有营业执照。所以这次注册的目标是
   **做到体验版能在我手机上跑**，不是正式发布。
   正式发布需要企业主体 + ICP 备案 + 金融类目资质，那是以后的事，这次不碰。

2. **不要复用我已有的小程序**。我之前做过一个叫「灵感速记」的小程序
   ，那是独立的另一个产品（其 AppID 见 `docs/LOCAL_CONFIG.md`）。
   这次必须注册**全新的 AppID**。

3. **云开发环境也要新建**。云开发环境绑定单个小程序，
   「灵感速记」那个环境（ID 见 `docs/LOCAL_CONFIG.md`）不能给这个项目用。

4. **不要用 computer-use 之类的工具去点我的屏幕**。
   我这台 Mac 上自动点击是失效的（会被系统拦截），你点了也没用还浪费时间。
   用文字告诉我点哪里就行。需要确认页面状态时，可以让我截图或描述给你。

5. **不要让我把身份证号、手机验证码这类信息贴给你**。
   那些直接填在微信官方页面上，你不需要看到。

## 我希望你怎么做

### 第一步：先去查当前的官方流程，别凭记忆讲

微信公众平台的注册流程和资质要求经常变。请先用 WebFetch / WebSearch
查一下官方文档的**当前**要求，再开始带我操作。至少要确认清楚：

- 个人主体注册小程序现在需要哪些材料
- 注册邮箱有什么限制（我记得有"未被微信公众平台注册过"之类的要求，
  请确认准确说法，并告诉我怎么判断某个邮箱能不能用）
- 个人主体能选哪些服务类目、明确不能选哪些
- **体验版是否需要先设置服务类目**，还是只有提交审核才需要
  （这条直接决定我这次要不要处理类目问题，请查准）
- 小程序备案（ICP）现在是什么时点要求的——注册后多久必须完成，
  不备案会影响开发和体验版吗

查完先把结论讲给我听，我们确认一遍再动手。

### 第二步：带我走注册

一步一步来，每步告诉我：点哪里、填什么、预期会看到什么。
一次只讲一步，等我说做完了再讲下一步。
遇到我描述的页面和你预期的不一样，先停下来搞清楚，不要硬往下推。

### 第三步：开通云开发环境

注册完成后带我开通云开发，选免费额度的环境。
帮我确认这个项目的数据量在免费额度内
（大约 12.5 万条指数日线 + 48 条快照 + 汇率表，可以看 docs/STATUS.md 的估算）。

### 第四步：验证能跑通

用微信开发者工具新建/打开项目，确认：
- AppID 填对了，能正常打开
- 云开发能初始化成功
- 能在开发者工具里看到云环境

我之前做「灵感速记」时装过微信开发者工具，应该还在。

### 最后：把结果写回项目

拿到之后，请把 **AppID** 和 **云环境 ID** 写进 docs/STATUS.md
（在「数据现状」附近新增一个「微信侧配置」小节），
并把 docs/TODO_USER.md 里第 5、6 两项勾掉。

这样我回到主 session 就能直接开始 P2 上云。

## 如果中途卡住

个人主体注册可能会遇到一些坑（邮箱被占用、身份证验证失败、
同一身份证注册数量上限等）。遇到就告诉我具体是什么限制、
有没有绕过办法、或者需要我换什么条件再来。不要含糊带过。
```
