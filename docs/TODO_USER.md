## 🔴 立即：解除当前阻塞

### ☐ 1. 真正关闭代理软件，补齐剩余 23 个指数

**为什么需要你**：代理软件的开关在你手上。

**上次为什么没成功**：你跑的 `env -u HTTP_PROXY ...` 无效，因为问题有两层，
清环境变量哪层都解决不了：

| 层 | 状况 |
|---|---|
| macOS 系统代理 | `scutil --proxy` 中 HTTP/HTTPS/SOCKS 全指向 `127.0.0.1:10808` |
| **TUN 路由劫持** | 路由表 `128.0/1 → utun28` 比 `default` 更具体，**全部流量强制进隧道** |

**正确做法**（二选一）：
- 把代理软件**完全退出**（不是断开连接，是退出 App）
- 或切到**规则模式 / PAC 模式**并确认 TUN 关闭 —— 这样国内站点直连，更省事

改完先验证出口 IP 变了再跑：

```bash
curl -s https://api.ipify.org
```

不是 `45.76.215.254` 就说明成功了，然后跑：

```bash
cd "/Users/weiyuhang/Desktop/AI工程项目/指数小程序" && python3 scripts/fetch_indices.py --force && python3 scripts/fetch_fx.py && python3 scripts/check_data.py; python3 scripts/build_snapshot.py && python3 scripts/build_prototype.py
```

**好消息：这件事现在不紧急了。** 我已经扩展了源链，找到三条境外 IP 也能直连的
新浪专用接口，把**核心 12 国全部补齐**（美股 22 年历史、港股 13 年、A 股 4 年）。
现在 25/48，缺的 23 个都在扩展/长尾层（新马泰、北欧、东欧等）加 3 个参考基准。

跑通后的预期：25 → 48，且各指数历史延长到 10 年，「近5年」窗口全面可用
（目前只有美国和香港有 5 年数据）。
